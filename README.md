# Task Dashboard

A full-stack task management app built with React + Node.js + Express.

## Stack
- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Database:** JSON file (no native dependencies)

## Run Locally

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:3000
